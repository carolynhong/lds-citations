# lds-citations
Citation network from October 2025 - October 2026 General Conferences (since Oaks became president).

Sociocentric network data, directed and weighted. Only general authorities are included (i.e., I do not include citations to scripture or non-Church materials). I also didn't include citations to Joseph Smith because there is too much overlap with scripture (e.g., Joseph Smith History and Teachings of The Prophet Joseph Smith). However, citations to all other General Authorities are counted from the time of Joseph Smith onward. It is rare that there are co-authors on speeches/devotionals/articles, but in these cases, all authors are cited if they hold an official Church leadership position.

Each Conference has its own .csv file containing an adjacency matrix (citations are marked with a 1 while the rest is blank). I also created a pooled adjacency matrix (matrix.csv) and edge list (edgelist.csv).

Also included is a .do file to read each individual adjacency matrix into an edge list.

RANK:
1. President
2. First Presidency
3. Quorum of the Twelve Apostles
4. General Officer OR Presiding Bishopric
5. Seventy (any)
