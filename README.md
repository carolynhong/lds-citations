# lds-citations
Citation network from October 2025 - October 2026 General Conferences (since Oaks became president).

Sociocentric network data, directed and weighted. Only general authorities are included (i.e., I do not include citations to scripture or non-Church materials). I also didn't include citations to Joseph Smith because there is too much overlap with scripture (e.g., Joseph Smith History and Teachings of The Prophet Joseph Smith). Each Conference has its own .csv file containing an adjacency matrix. I also created a pooled adjacency matrix (matrix.csv) and edge list (edgelist.csv).

It is rare that there are co-authors on speeches/devotionals/articles, but in these cases, all authors are cited.
